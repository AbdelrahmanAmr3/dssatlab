# Decisions

Architecture Decision Records (ADRs) document architectural and design choices in `dssatlab`, describing the context, options evaluated, and consequences of each decision.

- [0001: The managed install prefix must be short](../adr/0001-short-managed-install-prefix.md): Limits the managed install prefix to 51 characters (`<cache>/dssatlab/<version>`) because DSSAT fails with substring out of bounds errors when reading `DSSATPRO.L48` lines with longer paths.
- [0002: pandas is accepted but never required](../adr/0002-optional-pandas.md): Accepts pandas DataFrames for tabular weather inputs while maintaining zero runtime dependencies and only importing pandas if a DataFrame is passed.
- [0003: PyYAML is accepted for management files but never required](../adr/0003-optional-pyyaml-for-management.md): Accepts YAML files for structured management input while keeping zero runtime dependencies, importing PyYAML only when a YAML path is passed, and supporting plain Python dictionaries natively.
- [0004: matplotlib is an optional extra, used only for plots](../adr/0004-optional-matplotlib-for-plots.md): Keeps matplotlib optional under the `plot` extra (`pip install dssatlab[plot]`), imported only when calling `plot_plant_growth()` or `result.plot()`, while output reading functions return plain rows with zero dependencies.
- [0005: Experiment data is one YAML that edits a copy of an existing FileX](../adr/0005-experiment-data-edits-an-existing-filex.md): All user-supplied FileX content is one per-treatment YAML, applied to a copy of the user's own FileX by adding a level and repointing the selected treatment; building a FileX from nothing is deferred.
- [0006: A FileX can be written from a fixed template, one field and one treatment](../adr/0006-filex-written-from-a-fixed-template.md): A separate FileX template YAML lets dssatlab write a FileX for one field, one treatment and one crop, taking station, coordinates and elevation from the weather data and the soil ID from the soil data; crops are added only after a real-DSSAT run.
- [0007: Evaluation is computed in Python, not through DSSAT's FileA and Evaluate.OUT](../adr/0007-evaluation-computed-in-python.md): dssatlab compares the user's observed data with the parsed Summary and Plant growth itself, using DSSAT's column names and units; nothing is written for DSSAT. The original reading restriction is superseded by ADR 0008.
- [0008: Read DSSAT's FileA/FileT and Evaluate.OUT, still write nothing for DSSAT](../adr/0008-read-filea-filet-and-evaluate-out.md): Reads supported FileA/FileT measurements into observed data and reads the DSSAT evaluation separately from the Evaluation computed in Python. DSSAT fills its measured columns only in some runs, so the simulation folder does not copy FileA/FileT. No FileA/FileT is written.
- [0009: Ten template crops, one model each; listing shows only template crops](../adr/0009-ten-template-crops-and-listing.md): Extends the FileX template to ten crops (maize, wheat, rice, soybean, potato, sorghum, pearl millet, barley, peanut, dry bean), each with one fixed model; adds potato-specific planting fields and harvest date; provides `list_crops()` and `list_cultivars()` reading only the installed Genotype folder for template crops.
