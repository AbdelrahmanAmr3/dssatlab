# DSSATLab

DSSATLab lets you drive the DSSAT crop model from Python without touching a shell:
find a working DSSAT, turn your own weather data into DSSAT files with strict checks,
then run simulations with it.

- [Guide](guide/index.md): install, run a FileX, run a simulation from your own weather data.
- [Reference and Architecture](reference/index.md): API, design and decisions.
