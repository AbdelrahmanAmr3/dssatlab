# Stock case inputs

These files are copied byte-for-byte from stock DSSAT 4.8.
Genotype files come from the installed DSSAT data directory and are not bundled.

| file | origin | what it is |
| --- | --- | --- |
| `UFGA8201.MZX` | DSSAT 4.8 `Maize/UFGA8201.MZX` | Gainesville 1982 maize FileX; treatments 1 and 3 share cultivar McCurdy 84aa (`IB0035`) and differ in irrigation |
| `UFGA8201.WTH` | DSSAT 4.8 `Weather/UFGA8201.WTH` | Daily Gainesville weather for the maize season |
| `UFGA7901.PNX` | DSSAT 4.8 `Peanut/UFGA7901.PNX` | Gainesville 1979 peanut FileX; treatment 1 uses Florunner (`IB0002`) |
| `UFGA7901.WTH` | DSSAT 4.8 `Weather/UFGA7901.WTH` | Daily Gainesville weather for the peanut season |
| `SOIL.SOL` | DSSAT 4.8 `Soil/SOIL.SOL` | Stock soil file containing maize profile `IBMZ910014` and peanut profile `IBPN910015` (Millhopper Fine Sand) |
