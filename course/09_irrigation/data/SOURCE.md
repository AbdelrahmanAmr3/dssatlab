# Stock case inputs

These files are copied byte-for-byte from stock DSSAT 4.8, as in lesson 01.
The FileX uses soil profile `IBMZ910014`; unchanged genotype files come from the installed DSSAT data directory.

| file | origin | what it is |
| --- | --- | --- |
| `UFGA8201.MZX` | DSSAT 4.8 `Maize/UFGA8201.MZX` | Gainesville maize FileX; treatment 1 uses McCurdy 84aa (`IB0035`) |
| `UFGA8201.WTH` | DSSAT 4.8 `Weather/UFGA8201.WTH` | Daily Gainesville weather for 1982 |
| `SOIL.SOL` | DSSAT 4.8 `Soil/SOIL.SOL` | Stock soil file containing Millhopper Fine Sand, profile `IBMZ910014` |
