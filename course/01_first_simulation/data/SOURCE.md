# Stock case inputs

These files are copied byte-for-byte from stock DSSAT 4.8; genotype files come from the installed DSSAT data directory.
The FileX names soil profile `IBMZ910014`, which is held in `SOIL.SOL`.

| file | origin | what it is |
| --- | --- | --- |
| `UFGA8201.MZX` | DSSAT 4.8 `Maize/UFGA8201.MZX` | Gainesville maize FileX with nitrogen and irrigation treatments |
| `UFGA8201.WTH` | DSSAT 4.8 `Weather/UFGA8201.WTH` | Daily Gainesville weather for 1982 |
| `SOIL.SOL` | DSSAT 4.8 `Soil/SOIL.SOL` | Stock soil file containing profile `IBMZ910014` (Millhopper Fine Sand) |
