# Stock case inputs

These files are copied byte-for-byte from stock DSSAT 4.8, using the same case as lesson 01.
Genotype files come from the installed DSSAT data directory; no extra case inputs are needed.

| file | origin | what it is |
| --- | --- | --- |
| `UFGA8201.MZX` | DSSAT 4.8 `Maize/UFGA8201.MZX` | Gainesville maize FileX, six nitrogen and irrigation treatments, cultivar McCurdy 84aa (`IB0035`) |
| `UFGA8201.MZA` | DSSAT 4.8 `Maize/UFGA8201.MZA` | FileA with end-of-season measurements for six treatments; grain yield is dry weight |
| `UFGA8201.MZT` | DSSAT 4.8 `Maize/UFGA8201.MZT` | FileT with dated growth measurements; the public reader retains CWAD, LAID and GWAD |
| `UFGA8201.WTH` | DSSAT 4.8 `Weather/UFGA8201.WTH` | Daily Gainesville weather for 1982 |
| `SOIL.SOL` | DSSAT 4.8 `Soil/SOIL.SOL` | Stock soil file containing profile `IBMZ910014` (Millhopper Fine Sand) |
