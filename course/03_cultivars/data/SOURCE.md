# Input sources

All inputs are unchanged stock DSSAT 4.8 files, distributed under DSSAT's BSD-style licence.
The FileX uses soil profile `IBSB910015`; unmodified genotype files come from the installed DSSAT data directory.

| file | origin | what it is |
| --- | --- | --- |
| `UFGA7901.SBX` | Stock DSSAT 4.8, `Soybean/UFGA7901.SBX` | Gainesville soybean FileX; treatment 1 is irrigated Bragg |
| `UFGA7901.WTH` | Stock DSSAT 4.8, `Weather/UFGA7901.WTH` | Gainesville daily weather for 1979 |
| `SOIL.SOL` | Stock DSSAT 4.8, `Soil/SOIL.SOL` | Stock soil file containing IBSB910015 (Millhopper Fine Sand) |
