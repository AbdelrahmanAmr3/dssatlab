# Input sources

All inputs are unchanged stock DSSAT 4.8 files, distributed under DSSAT's BSD-style licence.
The soil file supplies the FileX's IBMZ910014 soil profile; unmodified genotype files come from the installed DSSAT data directory.

| file | origin | what it is |
| --- | --- | --- |
| `UFGA8201.MZX` | Stock DSSAT 4.8, `Maize/UFGA8201.MZX` | Gainesville maize FileX; treatment 1 and its original planting details |
| `UFGA8201.WTH` | Stock DSSAT 4.8, `Weather/UFGA8201.WTH` | Gainesville daily weather for 1982, including PAR |
| `SOIL.SOL` | Stock DSSAT 4.8, `Soil/SOIL.SOL` | Stock soil profiles, including IBMZ910014 used by the FileX |
